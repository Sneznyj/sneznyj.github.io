# sneznyj.github.io

Корень сайтов на GitHub Pages: главная переводит на [Вокал-Студию](https://sneznyj.github.io/vocal-studio/),
`robots.txt` показывает поисковикам карту сайта, здесь же лежат файлы подтверждения прав (Яндекс.Вебмастер).
Сами сайты живут в своих репозиториях (vocal-studio, alina-malyshko) и этот репозиторий не затрагивает их.
